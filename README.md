echo "# 🔐 FileSecurityApp

A Flutter-based application focused on enhancing **file security** and **user privacy**. The app allows users to encrypt and decrypt their files securely and efficiently with a clean UI and intuitive user experience.

## 📱 Features

- 🔒 **File Encryption & Decryption**
- 📂 Secure storage and retrieval of sensitive files
- 🧑‍💼 User-friendly interface
- 🚀 Fast and reliable performance
- 📱 Works across Android devices

## 🛠️ Tech Stack

- **Flutter** – Frontend framework
- **Dart** – Programming language
- **Provider** – State management
- **File Picker** – Selecting files
- **Path Provider** – Accessing device directories
- **Encrypt** – For file encryption and decryption
- **Shared Preferences** – To store settings securely

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or VS Code
- Android device/emulator

### Setup Instructions

1. Clone the repo:

   \`\`\`bash
   git clone https://github.com/GauravDesale08/FileSecurityApp.git
   \`\`\`

2. Navigate to the project directory:

   \`\`\`bash
   cd FileSecurityApp
   \`\`\`

3. Install dependencies:

   \`\`\`bash
   flutter pub get
   \`\`\`

4. Run the app:

   \`\`\`bash
   flutter run
   \`\`\`

## 🧠 How It Works

1. The user picks a file from device storage.
2. The file is encrypted using the \`encrypt\` package.
3. The encrypted file is saved in a secure location.
4. The user can decrypt the file later using the app.
